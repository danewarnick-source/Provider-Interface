# HIVE Audits & Technical Reports Archive

## Documents

- [LAUNCH_READINESS_AUDIT.md](LAUNCH_READINESS_AUDIT.md) — Launch readiness verification, EVV compliance checks, and operational gating.
- [REPO_CLEANUP.md](REPO_CLEANUP.md) — Codebase consolidation audit identifying legacy generations, unimported components, and safe cleanup boundaries.
- [ROUTE_MAP.md](ROUTE_MAP.md) — Complete URL route hierarchy and permission gate map.
- [SCHEMA_AUDIT.md](SCHEMA_AUDIT.md) — Database schema verification, RLS policies, and PostgREST table structures.
- [SECURITY_AUDIT.md](SECURITY_AUDIT.md) — HIPAA/PHI security posture, Cognito authentication gates, and RBAC enforcement.
